# Shortcut Parity Matrix

**Last updated:** 2026-06-01

This matrix tracks Excel-for-Windows shortcut fidelity for the visible FreeX command surface. Status values use the command-surface contract: Parity, Partial, Excluded, or Missing. Exact command shortcuts reject unrelated extra modifiers so combinations such as Ctrl+Alt+C or Ctrl+Shift+C do not steal AltGr/non-US input or future shortcut space.

## Next Shortcut Work

Shortcut parity is complete for the current visible FreeX surface. The items below are future fidelity polish or broader Excel-surface expansions; they are not missing-shortcut blockers.

1. Deepen the full Excel Print backstage/settings editing flow behind `Ctrl+P`; the current path opens FreeX's print preview immediately through File/Backstage Print, with a native print-dialog button, active-sheet settings summary, and non-destructive ignore-print-area option.
2. Add future `Ctrl+V` and `Ctrl+Alt+V` paste/Paste Special fidelity beyond the currently supported values/formulas/formats/values-and-source-formatting/all-using-source-theme/all-except-borders/all-merging-conditional-formats/arithmetic/skip-blanks/transpose/link/picture/linked-picture/column-width/comments/validation/number-format paths.
3. Continue broadening Format Cells for `Ctrl+1` and `Ctrl+Shift+F/P` beyond the supported style model and current number-control composition toward Excel's full multi-page dialog; the Font tab now keeps superscript and subscript mutually exclusive like Excel.
4. Deepen `Ctrl+Shift+F2` from the current model-backed threaded-comment entry point into full Excel threaded conversation/reply UI and XLSX threaded-comment package fidelity.
5. Polish the `Alt+Down` Excel visual menu layout beyond the current Excel-style filter menu plan with nested filter-family commands, two-condition custom criteria, and richer visual fidelity for the keyboard-activatable color swatches.
6. Expand in-grid visual Quick Analysis hover-preview rendering and the remaining Excel gallery options for `Ctrl+Q`; current live preview coverage includes icon-sized menu swatches plus status/target metadata, keyboard-verified adjacent-column total/sparkline targeting, proportional data-bar, color-scale, and icon-set worksheet previews, lightweight highlight/clear-format/total/table overlays, compact line/column/win-loss sparkline previews, lightweight column-, stacked-column-, line-, bar-, pie-, doughnut-, area-, scatter-, and bubble-chart previews, More Charts, and percent/running-total formulas rather than Excel's full rendered worksheet gallery.

8. Expand `Shift+F10` / Menu key toward the remaining full Excel worksheet context menu entries beyond the current command-backed worksheet, row/column-selection, and active-cell object menus.
9. Continue deciding which remaining dialog-driven workflows should become repeatable through F4 and add explicit repeat command objects only for safe replay paths; Goal Seek and Forecast Sheet are intentionally guarded as non-repeatable because they require fresh dialog/status review before applying model changes.
