## Summary

Since the 2026-06-24 snapshot, close to 9,200 commits landed on `origin/main`. The dominant movements were:

- **FreeP (presentation/PowerPoint-like sibling app)**: sustained functional-depth work across roughly 2,600 commits touching `freep/`, including native WPF printing and video export for shared layouts, muxed persisted narration into WPF video export, Windows `MediaComposition` video export (delayed narration tracks, picture-in-picture camera overlay, `ftyp`/`moov`/`mdat` validation), Windows OLE in-place activation in both the WPF host and the Avalonia Windows native-control bridge, and package-owned recording/caption sidecar retention on save. The 2026-08-06 functional-parity audit (`docs/planning/freep-functional-parity-audit-2026-08-06.md`) reports no actionable WPF/Avalonia command-surface gap; remaining work is depth, external capability evidence (live mic/camera, PowerPoint-authoritative COM baselines), and package/media execution rather than missing ribbon routes. Visual-fidelity work for FreeP remains intentionally paused.
- **FreeW (sibling `.docx` word processor)**: the largest single share of fidelity activity, with roughly 2,000 commits touching `freew/` and close to 200 dated fidelity-parity records added under `docs/fidelity/` (through 2026-08-02) covering settings/rendering/package parity for hidden text, page borders/headers/footers, spelling-error display, link styles, personal-information removal, subset-font saving, tracked-formatting selection, and related WPF/native-package contract work.
- **Avalonia cross-platform shell**: continued parity hardening (roughly 740 commits touching `src/FreeX.App.Avalonia`), including missing-parity dialog and shared-ribbon work reflected in the newly added `docs/parity/avalonia-parity-wave81-freew-20260731.md`, `docs/parity/avalonia-parity-wave81-shared-ribbon-20260731.md`, and `docs/parity/ribbon-wave84-split-button-parity.md` records.
- **Chart, PivotTable, and PDF work**: continued as an active fidelity workstream layered on top of the intensive PivotTable style/chrome passes already underway at the 2026-06-24 snapshot; native WPF printing and PDF/video export paths for FreeP, and continued native pivot slicer/tabular-cache metadata work (for example the required `pivotCacheId` fix on the native pivot slicer tabular cache) landed in this window.

The XLSX fidelity contract (`docs/formats/fidelity-contract.md`) and the workbook adapter catalog are unchanged in scope since 2026-06-24; that surface remained stable while FreeP/FreeW/Avalonia absorbed the bulk of new work in this window.

The latest verified tester release found through the GitHub Releases API is **v0.8.166**, published 2026-07-30 from Tester Release run 166 attempt 2 at commit `68ee50ce` — GitHub's `releases/latest` non-prerelease pointer. Separate app-scoped platform tags are published as pre-releases (FreeX Linux, FreeW, FreeP). Current `origin/main` at `8e288fe0ee` is the next tester-release candidate beyond that published build. It remains an internal tester release, not a public-preview promotion, because live keyboard-only, screen-reader, UI Automation catalog, and known-issues accessibility evidence must still be recorded for public-preview eligibility.
