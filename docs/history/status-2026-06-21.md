# FreeX Status - 2026-06-21

Report scope: documentation refresh, repository hygiene, and current `origin/main` state as of 2026-06-21.

Mainline observed: branch-neutral `origin/main` snapshot at `8300516e` after the June 21 documentation refresh.

## Summary

FreeX remains in late-stage fidelity and release hardening. The current tree has moved beyond the June 12 documentation baseline: spreadsheet file-format work now includes in-house ODS support, legacy XLS/XLSB/XLT open support, SpreadsheetML 2003, SYLK, DIF, DBF open-only, HTML table import/export, CSV variants, tabular text, XLTX templates, and the native `.fxl` JSON format. FreeW also moved beyond its original DOCX-only planning surface and now has a broad document-format adapter lane plus a real-world DOCX fidelity corpus.

The latest verified tester release found through the GitHub Releases API is **v0.8.127**, published on 2026-06-20 from Tester Release run 127 attempt 1 at commit `1790d2abdc7112047382c3f19fcb417eb0227059`. It is still an internal tester release, not a public-preview promotion, because live keyboard-only, screen-reader, UI Automation catalog, and known-issues accessibility evidence must be recorded for public-preview eligibility.
