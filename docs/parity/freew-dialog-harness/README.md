# FreeW Dialog Visual Harness

This evidence bundle is generated by `freew/tools/FreeW.DialogVisualHarness` from the current WPF and Avalonia source trees. The source-hashed inventory contains only applicable lifecycle and tab states for each dialog, pane, overlay, and Backstage surface.

## Run

```powershell
dotnet run --project freew/tools/FreeW.DialogVisualHarness/FreeW.DialogVisualHarness.csproj -c Release -- inventory --repo-root . --output docs/parity/freew-dialog-harness
dotnet run --project freew/tools/FreeW.DialogVisualHarness.Wpf/FreeW.DialogVisualHarness.Wpf.csproj -c Release -- --inventory docs/parity/freew-dialog-harness/freew_dialog_evidence_inventory.json --output artifacts/freew-dialog-harness/about-legal-final-wpf
dotnet run --project freew/tools/FreeW.DialogVisualHarness.Avalonia/FreeW.DialogVisualHarness.Avalonia.csproj -c Release -- --inventory docs/parity/freew-dialog-harness/freew_dialog_evidence_inventory.json --wpf-authority artifacts/freew-dialog-harness/about-legal-final-wpf/wpf_dialog_capture_manifest.json --output artifacts/freew-dialog-harness/about-legal-final-avalonia
dotnet run --project freew/tools/FreeW.DialogVisualHarness/FreeW.DialogVisualHarness.csproj -c Release -- compare --inventory docs/parity/freew-dialog-harness/freew_dialog_evidence_inventory.json --wpf artifacts/freew-dialog-harness/about-legal-final-wpf/wpf_dialog_capture_manifest.json --avalonia artifacts/freew-dialog-harness/about-legal-final-avalonia/avalonia_dialog_capture_manifest.json --output docs/parity/freew-dialog-harness
dotnet run --project freew/tools/FreeW.DialogVisualHarness/FreeW.DialogVisualHarness.csproj -c Release -- compare --inventory docs/parity/freew-dialog-harness/freew_dialog_evidence_inventory.json --wpf artifacts/freew-dialog-harness/about-legal-final-wpf/wpf_dialog_capture_manifest.json --avalonia artifacts/freew-dialog-harness/about-legal-final-avalonia/avalonia_dialog_capture_manifest.json --output docs/parity/freew-dialog-harness --check
```

`--check` is supported by both `inventory` and `compare` and validates the tracked JSON, Markdown, HTML, and freshness sidecar byte-for-byte. Avalonia uses the Skia renderer with `UseHeadlessDrawing = false` and captures compositor frames through `CaptureRenderedFrame`. Every Avalonia full image and target crop must pass opacity, near-black, dominant-color, color-variation, luminance-range, and painted-bounds gates before its manifest row can be `captured`.

The comparison normalizes both sides to 96-DPI logical target dimensions, emits target crops and heatmaps, and reports focus/default/cancel/action-order metadata independently from image metrics. Desktop DPI is recorded as environment metadata, not used as a parity exemption.

Both capture hosts accept `--route <route-id>` for a complete route-local manifest or
`--scenario <host.scenario-id>` for one state. Route-local manifests can be merged into the
canonical comparison with `--baseline` and `--refresh-route` without fabricating unrelated rows.

Paste Special, Style, and Manage Styles are content-sized WPF static prompts rather than the harness's standard fixed-size routes. Their Avalonia captures therefore consume the freshly captured WPF manifest through `--wpf-authority`, ensuring both hosts are rendered at the same WPF-authority outer dimensions. Avalonia-only routes retain their own declared capture dimensions.
