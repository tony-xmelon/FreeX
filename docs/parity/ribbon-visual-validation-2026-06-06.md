- Target data region for filter/sort validation: `FilterData!A1:H10`

FreeX visual evidence:

- Full main-ribbon matrix: `screenshots/ribbon_screenshot_tour_manifest.json`
- Captures: 36 PNGs covering Home, Insert, Draw, Page Layout, Formulas, Data, Review, View, and Help at max, 1100, 900, and 750 widths.
- The tour was run with `FREEX_SS_TOUR=1`, `FREEX_SS_TOUR_WIDTHS=max,1100,900,750`, and `FREEX_SS_TOUR_STARTUP_DELAY_MS=2500` so the startup workbook was loaded before capture.

Excel behavior check for Data > Filter:

```json
{"AutoFilterMode":true,"FilterMode":false,"AutoFilterRange":"A1:H10","HeaderCount":8}
{"AfterSecondToggleAutoFilterMode":false,"HasAutoFilterObject":false}
```

Interpretation: Excel toggles AutoFilter arrows for the current region (`A1:H10`) without applying criteria, and a second toggle removes the AutoFilter object.

Excel screenshot sweep status:

- `tools/screenshot_excel.ps1` was improved to accept `-WorkbookPath`, launch Excel with `/x`, bind capture/cleanup to the launched PID, and tolerate empty-title foreground child windows from the same Excel process.
- A full Excel ribbon screenshot sweep was still blocked when another foreground app took focus. The script aborted and discarded partial evidence as designed.
