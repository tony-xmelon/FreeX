`05C18987BB2824854BCFC89038E82F1F553612D101BC3E13E93C2B695CD6EAA1`.

## Change

The WPF and Avalonia baseline routes now fragment an overflowing baseline
paragraph at word boundaries and draw each fragment against a shared line
baseline. Baseline-aware font scaling and signed vertical offsets are applied
per run. Explicit line breaks and overlong single words are handled locally;
math, tabs, effects, and ordinary paragraph wrapping retain their existing
owners.
