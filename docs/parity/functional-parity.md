# FreeX functional parity matrix (WPF vs Avalonia/Linux)

Generated by `FunctionalParityMatrixTests.EmitArtifacts`. Do not edit by hand.

Each row is a canonical command id the shared ribbon definition (`FreeXRibbon.Build()`) emits. `WPF` = the WPF host binds a Click handler for the id (`FreeXRibbonHandlerMap`). `Avalonia` = the Avalonia shell binds a ribbon-command-registry handler for the id (the shared ribbon definition + the shell's canonical endpoint dictionaries, cell-style gallery, and chart factory).

> Caveat: coverage is measured at the *command-binding* layer of each shell. Non-parity rows are classified in `functional-parity-classification.md/json` so command-binding inventory noise does not get mistaken for product behavior work. Gates reject real behavior gaps in either direction.
