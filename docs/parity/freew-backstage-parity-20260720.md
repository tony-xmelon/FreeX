## Lifecycle And State

| Contract | WPF authority | Avalonia realization |
| --- | --- | --- |
| Back / Escape | Hide Backstage and return to the document host | Shared frame hides the modal and restores prior owner focus |
| Pane activation | Keep Backstage open, select the rail row, replace pane content | Matched by shared frame state |
| Direct command | Dismiss Backstage before invoking host callback | Matched by shared frame command dispatch |
| Save | Save current document, falling back to Save As when untitled | Host-backed and distinct from Save a Copy |
| Save a Copy | Write a separate file without changing active path or dirty state | Host-backed and covered by dialog-free state tests |
| Close | Close through the window Closing dirty gate | Host callback calls `Close`; shared file workflow owns Save/Don't Save/Cancel |
| Properties | Edit Title, Author, Subject, Keywords, and Comments from Info | Host-backed Avalonia dialog marks accepted edits dirty |

## Remaining Platform Gaps

- Avalonia has no native printer-selection service in the current target; direct print remains deferred while preview and PDF are available.
- Avalonia has no XPS writer; XPS remains WPF-only and is omitted from the Avalonia Export pane.
- Foreground OS validation of printer dialogs, file pickers, modal focus restoration, and accessibility announcement order remains platform-runner evidence, not headless proof.
- Cloud places, account-backed sharing, and online template/search services remain outside this local Backstage slice.
