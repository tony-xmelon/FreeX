# Imported Chart Native Visual Semantics

## Scope

`chart-smartart-complex.docx` carries native Office chart parts whose `c:style` values are
family-specific themes. Their concrete visual elements must remain authoritative when the
chart is imported into FreeW.

## Reference

- Input DOCX: `chart-smartart-complex.docx`
- Manual Word PDF SHA-256: `CA922FF74B8F326458683990C0EEF31BFAFB1C439EC7F4957BE52ACE3F132198`
- Raster target: 816x1056 px, generated by requesting 1020x1320 from `FreeW.PdfRasterize`.
  The WinRT raster surface currently returns 80% of its requested dimensions.

## Source facts

- `chart1.xml`: `c:style=7`, no plot-area fill, no data labels, major gridlines present.
- `chart2.xml`: `c:style=4`, no plot-area fill, no data labels, no gridlines, and
  `c:scatterStyle=lineMarker`.

## Accepted result

The importer records concrete native visual settings. The shared planner and writer prefer
them over the synthetic FreeW gallery mapping, while model-authored charts without imported
settings retain their existing gallery behavior.
