# FreeX Scenario Manager Wave 28

Date: 2026-07-27

## Diagnosis

The Avalonia route already used the shared Scenario Manager planners and seeded
the same scenario data as WPF. The visual outlier was the shell composition:
Avalonia placed actions beside a vertically growing editor, used stacked labels,
and wrapped the fixed-size dialog in a scroll viewer. Its 170px input minimums
then collided with the label column at the 360px dialog width.

## Bounded fix

- Recreated the WPF two-column body: fixed scenario list, right-side action
  buttons, bordered Add/Edit group, and bottom-right Close action.
- Reused `AvaloniaCompactDialogChrome` for the window, list, buttons, text
  inputs, checkboxes, and group border.
- Matched WPF field rows with a 92px label column and six compact rows.
- Kept validation text in its own root row so it cannot overlay the body or
  Close action.
- Removed the per-input minimum width inside this fixed dialog so fields stretch
  within the available body width.
