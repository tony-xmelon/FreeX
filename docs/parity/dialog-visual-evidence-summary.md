# Dialog visual evidence summary

Generated by tools/Generate-DialogVisualEvidenceSummary.ps1 from committed dialog capture manifests, PNG evidence, and the generated dialog parity inventory.

Dimension comparisons are DPI-normalized to 96-DPI logical units so high-DPI WPF captures are compared like-for-like with Avalonia logical captures; raw PNG pixel dimensions remain reported as capture metadata.
