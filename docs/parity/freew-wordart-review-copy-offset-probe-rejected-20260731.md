# WPF Review Copy Offset Probe

## Scope

The fresh Word baseline for `wordart-watermark-stress.docx` was generated by
the repaired Word PDF export path at 816x1056. The candidate adjusted only the
exact imported `Review Copy` WordArt signature:

- `FillGold`
- `ArchUp`
- 34--35 DIP imported font size

The gold material surface was left unchanged. The probe moved the glyph
placement 3 DIPs up and left, based on the raw glyph-band envelope.

## Result

The actual rebuilt Release `FreeW.FidelityRender` candidate regressed against
the same Word PNG:

| Region | Baseline | Candidate |
| --- | ---: | ---: |
| Whole page | 4.2071% | 4.2526% |
| Review Copy ROI `(440,360)-(690,440)` | 4.4226% | 6.3865% |

The candidate was reverted before this evidence was recorded. Focused WordArt
host tests passed 42/42 and both candidate and restored FidelityRender builds
completed with 0 warnings and 0 errors.

## Decision

The raw WPF/Word glyph-band offset is not an object-anchor error. `Review
Copy` remains a warped-text/material rasterization residual; do not retry a
plain position correction. Any future probe must isolate the ArchUp glyph-path
or its material/compositor layer and still pass the target ROI plus whole-page
gate.
